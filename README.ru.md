# Polygraph

**Учи новый язык через языки, которые уже знаешь.**

[English version](README.md) · [Скачать](https://github.com/Vorchunello/polygraph/releases) · [Дорожная карта](docs/ROADMAP.md)

Большинство приложений учат язык так, будто ты знаешь только один другой. Но если ты говоришь по-русски, по-турецки и по-английски и учишь испанский, половина работы уже сделана: *noche* — родственник *ночи* и *night*; *aceite* (масло) и турецкое *zeytin* (олива) восходят к арабскому — *az-zayt* и *zaytūn*; *la mesa* — женского рода, хотя *стол* мужского, и именно эту ловушку стоит запомнить.

Polygraph хранит слово как **понятие с мостами**: само слово на каждом из твоих языков плюс связи между ними — общие корни, заимствования, совпадающий или несовпадающий род, ложные друзья. Каждый мост помечен как *надёжный*, *частичный* или *ловушка*.

## Что умеет v0.1

- **Многоязычный словарь** — таблица или карточки, слово сразу на всех твоих языках, род выделен цветом, мосты и ловушки отмечены.
- **Черновик слова от ИИ** — вводишь слово на любом языке, ИИ заполняет переводы, род, артикли, мосты, этимологию и примеры. Всё от ИИ помечено «не проверено», пока ты не подтвердишь.
- **Маршруты** — ты решаешь, какой язык объясняет какую тему: род — через русский, артикли — через английский, идиомы — с подходящими идиомами из каждого известного языка.
- **Интервальное повторение** — *узнавание* (видишь слово, вспоминаешь значение) и *вспоминание* (видишь слово сразу на всех своих языках, вспоминаешь на изучаемом).
- **Инбокс** — записываешь незнакомое на ходу, ИИ разбирает пачкой.
- **Вопросы** — грамматика и употребление, ответ по твоим маршрутам.
- **Рассказы из твоих слов** — IELTS Reading, диалог, сказка, новость, дневник, метод Ильи Франка или *diglot weave* (текст на родном языке, где слова изучаемого постепенно вытесняют родные).
- **Любой ИИ** — локальные модели на ПК (LM Studio, Ollama) или API (OpenRouter, OpenAI, DeepSeek, Gemini, Anthropic Claude). С телефона можно ходить к LM Studio на ПК по Wi-Fi.
- **Данные — это Markdown** — по md-файлу на слово в папке, которую выбираешь сам. Открывается в Obsidian, кладётся в git, синхронизируется через Syncthing.
- **Импорт и экспорт** — CSV (колонки — коды языков), текстовые файлы Anki, резервная копия JSON.
- **15 языков первого класса** с подсказками по грамматике и ещё 15 — плюс любой другой по ISO-коду, потому что основную работу делает ИИ. Интерфейс: английский и русский, другие на подходе ([помочь с переводом](docs/TRANSLATING.md)).

## Установка

Скачай из [Releases](https://github.com/Vorchunello/polygraph/releases):

| Платформа | Файл |
|---|---|
| Windows | `Polygraph.Setup.x.y.z.exe` (установщик) или `Polygraph.x.y.z.exe` (portable) |
| Linux | `Polygraph-x.y.z.AppImage` |
| Android | `Polygraph-x.y.z.apk` — разреши установку из неизвестных источников |

Сборки пока без цифровой подписи, поэтому Windows SmartScreen предупредит при первом запуске: *Подробнее → Выполнить в любом случае*.

## Настройка ИИ

Настройки → ИИ:

- **Локально, бесплатно, приватно:** поставь [LM Studio](https://lmstudio.ai), скачай модель (Qwen 3 8B, Gemma 3 12B или больше, если позволяет видеокарта), *Developer → Start server*. В Polygraph выбери *LM Studio* и нажми *Загрузить список*.
- **API:** выбери провайдера, вставь ключ, загрузи список моделей. Ключи хранятся только на устройстве и не попадают в хранилище.

Маленькие локальные модели чаще ошибаются в этимологии — поэтому любой мост от ИИ сначала «не проверен».

## Хранилище

Формат описан в [docs/VAULT_FORMAT.md](docs/VAULT_FORMAT.md). На Windows по умолчанию `Документы\Polygraph` (меняется в Настройки → Данные), на Android — `Documents/Polygraph`.
